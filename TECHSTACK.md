# Tech Stack

LexPage is built using a modern stack of technologies to ensure performance, scalability, and a great developer experience.

## Core Framework

-   **[Next.js 14](https://nextjs.org/)**: The React framework for the web. Used for its App Router, server-side rendering capabilities, and easy routing.
-   **[React](https://react.dev/)**: The library for web and native user interfaces.
-   **[TypeScript](https://www.typescriptlang.org/)**: Adds static typing to JavaScript, improving code quality and maintainability.

## Styling

-   **[Tailwind CSS](https://tailwindcss.com/)**: A utility-first CSS framework for rapid UI development.
-   **[Shadcn UI](https://ui.shadcn.com/)**: A collection of re-usable components built using Radix UI and Tailwind CSS. Used for consistent and accessible UI elements (Dialogs, Dropdowns, Buttons, etc.).
-   **[Lucide React](https://lucide.dev/)**: Beautiful & consistent icon library.
-   **[Next Themes](https://github.com/pacocoursey/next-themes)**: For seamless dark mode implementation.

## Editor & Document Processing

-   **[Tiptap](https://tiptap.dev/)**: A headless wrapper around ProseMirror for building rich text editors.
-   **[html2pdf.js](https://github.com/eKoopmans/html2pdf.js)**: Client-side PDF generation.
-   **[html-docx-js-typescript](https://github.com/private-face/html-docx-js-typescript)**: For converting HTML content to DOCX format.
-   **[File Saver](https://github.com/eligrey/FileSaver.js)**: For saving files on the client-side.

## State Management & Utilities

-   **[date-fns](https://date-fns.org/)**: Modern JavaScript date utility library.
-   **Local Storage**: Used for persisting documents on the client side without a backend database.

## Development Tools

-   **[ESLint](https://eslint.org/)**: Pluggable JavaScript linter.
-   **[PostCSS](https://postcss.org/)**: Tool for transforming CSS with JavaScript.
